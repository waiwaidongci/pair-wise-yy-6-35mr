# 墨锭试磨室

墨锭养护与试磨流程管理：入室建档绑定生产批次、养护时长与温湿度范围，养护到期才能初评，初评达标满 24 小时后复磨定级。

## 运行

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`。

## 测试

```bash
npm test
```

## 流程规则

1. **入室建档**：必填墨锭编号、生产批次、养护时长（天）、温度范围、湿度范围；可登记入室即时温湿度作为计时起点。
2. **养护计时**：只累计温湿度落在设定范围内的时间。读数超标时计时暂停并记录暂停原因；回到范围后从暂停点续算，不产生跳变。每次温湿度读数都留档。
3. **初评**：养护未到期不能初评。初评达到 85 分进入「待复磨」，未达 85 分直接转「重点观察」。
4. **复磨**：初评满 24 小时后才能复磨。复磨比初评低 5 分（含）或出现沉淀，转「重点观察」；否则按复磨评分「已定级」。
5. 页面按批次分组展示每锭的剩余养护时间、暂停原因和下一步操作，并保留全部温湿度与试磨记录。

状态机：`养护中 → 待初评 → 待复磨 → 已定级`，任何阶段异常进入 `重点观察`。

## 代码分层

| 文件 | 职责 |
| --- | --- |
| `src/rules.js` | 判定规则（纯函数）：养护计时/暂停续算、到期流转、初评门槛、24 小时复磨窗口、降分与沉淀判定 |
| `src/store.js` | 数据保存：JSON 读写、首建种子数据、旧版数据迁移 |
| `src/page.js` | 页面：批次分组看板、建档/温湿度/初评/复磨表单 |
| `server.js` | HTTP 编排：解析请求 → 调用规则 → 保存数据 |
| `test/rules.test.js` | 规则单元测试（`npm test`） |

## API

- `GET /api/items` 列表（含剩余养护时间、暂停原因、下一步）
- `POST /api/items` 入室建档
- `POST /api/items/:id/readings` 单锭温湿度登记
- `POST /api/batches/:batch/readings` 按批次温湿度登记（作用于该批次养护中的墨锭）
- `POST /api/items/:id/initial` 初评
- `POST /api/items/:id/regrind` 复磨定级
- `GET /api/stats` 状态统计

旧版数据（一次评分定结论的档案）在首次启动时自动迁移：历史评分保留在记录中仅供追溯，墨锭按养护已到期进入「待初评」，需重新走初评与复磨流程。
